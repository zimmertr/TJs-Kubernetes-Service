# NNNN. The decision, as one sentence

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD
- Decider: who made the call
- Issues and PRs: #N

## Context

What forced a decision, and the facts that were true at the time.

## Decision

What was decided, stated so a reader can check the code against it.

## Evidence

Measurements, documentation or tests that settled it, each dated.

## Alternatives rejected

- Each alternative and the reason it lost.

## Consequences

What this makes easier, what it makes harder, and what must now stay true.
